# Code Tour Skill

当目标含「导览 / 上手 / onboarding / 入口」时：

1. `list_dir` → 找出 `src/`、`apps/`、`packages/`、`docs/`  
2. 读入口文件（如 `src/index.ts`、`package.json` scripts）  
3. 读 `docs/ARCHITECTURE.md`（若有）  
4. 输出「5 分钟导览」：

- 这是什么  
- 从哪进  
- 关键目录地图  
- 本地怎么跑  
- 下一步建议读什么  

保持短句，可勾选清单。

# Repo Hygiene Skill

当目标含「git 状态 / 仓库卫生 / 脏文件 / hygiene / 提交前检查」时：

1. `run_safe_cmd`：`git status`（需批准）  
2. 视情况再跑：`git diff`、`git log -n 10`（均在白名单内，需批准）  
3. 汇总：

| 项 | 内容 |
|----|------|
| 分支 | … |
| 脏文件数 / 类型 | 已跟踪改动 / 未跟踪 |
| 风险 | 是否含 `.env`、密钥痕迹、大二进制 |
| 建议下一步 | 提交前忽略 / 拆提交 / 继续改码 |

规则：

- 默认**只报告**；除非用户明确要求，才用 `write_file` 写卫生纪要（仍走 Diff）  
- 不要执行 `git add` / `commit` / `push`（不在白名单）  
- 命令失败时原样展示 stderr，并给出人工排查建议
